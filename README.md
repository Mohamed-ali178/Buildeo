# Buildeo

Application de gestion de chantiers (interface en français).

Fonctionne dans le navigateur, s’installe sur le bureau, et peut être ajoutée à l’écran d’accueil sur iOS et Android.

## Lancer

```
node server.js
```

Puis ouvre http://127.0.0.1:5173

Les chantiers restent dans le navigateur. Les comptes (e-mail, mot de passe, photo) sont enregistrés sur le serveur local.

Pour l’e-mail de vérification, remplis `email-config.json` (Gmail + mot de passe d’application). L’expéditeur prévu est yakoubidali7@gmail.com.
